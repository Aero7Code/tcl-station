# TCL Station

An **unofficial, early-stage** Android 12+ dashboard for **arm64-v8a tablets** repurposed as tabletop control panels. The current APK contains only arm64-v8a native speech libraries; other CPU architectures are not supported by that APK. The app is written in Java with the Android SDK and does not require Google Play services. It is not affiliated with TCL, Amazon, or Google.

## What works now

- Landscape-first, three-page dashboard with seven tap-to-expand cards; double-tap a card to collapse it.
- Weather from Open-Meteo for a **configurable fixed area** (default: example Denver city-center point; no GPS permission), Denver-time clock, and Android camera/timer/alarm and YouTube Music shortcuts.
- A short, intentionally quiet audio-test beep and a separate **Test spoken reply** button in the expanded Studio Audio card. The same card lets you switch between the tablet's original system voice and an alternate local English voice; tap the switch to hear a sample. If that alternate voice is unavailable on your device, the app falls back to the system voice. Voice quality is subjective—listen on the Echo Studio before keeping it. Android manages wired output; Echo Studio aux beep playback was tested with one tablet, but this app does **not** control Echo firmware or the speaker's microphone.
- Live **on-tablet** camera preview with front/back switching. It is visible only while the preview is open and saves or uploads no footage. The old experimental recorder has been removed; on upgrade, the app attempts to delete clips it created in its own private storage.
- **Speak** remains push-to-talk: tapping it opens an installed Android speech recognizer (also available inside the camera preview). That external recognizer may use the network and process audio/transcripts under its own policies; offline processing is not guaranteed.
- **Hands-free** is a separate, opt-in continuous listener. Tap **Hands-free: Off** to request microphone permission and start a foreground microphone service; tap **Hands-free: On** or the persistent notification's **Stop listening** action to stop it. While enabled and running, it captures tablet-microphone audio even with the screen off or another app visible. Bundled Vosk recognition runs locally/offline; Station does not save audio or transcripts or send them to a Station server. Say **“Hey Station”** alone for an “I'm listening” spoken acknowledgment, then one bounded command within 35 seconds; alternatively say **“Hey Station”** or **“Station”** followed immediately by a command (for example, “Hey Station show weather” or “Station stop listening”). This matches *final recognized phrases*, not a guaranteed dedicated wake-word detector: misrecognition and false activations are possible. The listener pauses during Speak and spoken responses, does not start at boot, and may stop if Android kills the service. Continuous listening uses additional battery. It uses the **tablet microphone**, not the Echo Studio microphone through aux.
- Both speech modes match returned text locally to **100 curated short phrases for ten existing actions** ([full list and limits](VOICE_COMMANDS.md)), plus earlier grammar such as “help” and bounded “set timer for five minutes.” These are not 100 separate integrations, and parser matching does not guarantee acoustic recognition of every phrase. The actions cover configured-area weather, Denver time, live on-tablet camera open/close, external Clock timer/alarms, opening YouTube Music, Station home, and Stop listening. Hands-free accepts “Hey Station stop listening” or “Station stop listening.” Time and weather answers can be spoken while Station is not foreground (weather uses the last locally cached summary, which may be stale); other hands-free commands require Station in the foreground and otherwise prompt you to open it. Time and weather replies use Android text-to-speech, whose provider may process text under its own policy. Timer duration is limited to two hours; external Clock handles the timer.
- Station can be selected as the Android **Home app** from page 3 using **Make Station Home**. This is a normal, reversible launcher choice, not kiosk mode or a boot receiver. **Home app settings** on the same page opens Android's default-Home settings to restore the previous launcher. Android's status shade, Settings, and app switching remain available.

**Not implemented:** a dedicated wake-word engine, background camera, remote streaming/control, recording, Hermes connection, motion alerts, and EQ. Hands-free is opt-in local phrase recognition, not a guarantee that every “Station” phrase is heard. The Echo Studio aux cable is **tablet audio output only**, not an input from the Studio microphone. The separate **Take photo** shortcut launches another camera app, which may save photos independently. This app has no accounts, analytics, or media upload; see [Privacy Policy](PRIVACY.md).

## Build

Install Android SDK **platform android-36** and **build-tools 36.0.0**, `mise` with `java@21.0.2`, Python 3, and standard JDK tools. Set `ANDROID_HOME` or `ANDROID_SDK_ROOT` to the Android SDK path; otherwise the script checks `$HOME/Work/tools/android-sdk`. Run:

```bash
bash build.sh
```

The build script runs local checks and produces `build/tcl-station-debug.apk`, signed by a locally generated **debug/prototype key**. Do not commit or distribute the private key. The APK is not a production-signed release. To install on your own authorized arm64-v8a tablet, use `adb install -r build/tcl-station-debug.apk`. Camera permission is requested when you open the live preview; microphone permission is requested only if you enable hands-free. Push-to-talk uses the installed recognizer separately. The bundled offline English model increases APK size (approximately 41 MB compressed / 71 MB unpacked for the model); allow room for extraction into the app-specific external-files directory (`Android/data/com.aero.tclstation/files`). After installing, you can opt into Station as Home on page 3; no boot automation is installed. On one Android 12 tablet, automated checks confirmed live local microphone capture, screen-off operation, Speak pause/resume, and explicit Stop. The spoken-reply test produced an Android TTS synthesis request and an audio player routed to the wired headphone output, then listening resumed. A user reported that hands-free Station works in the room, but individual catalog phrases and the new voice's subjective quality have not been systematically checked by a listener; the automated checks cover parser matching and microphone/TTS lifecycle, not room-acoustic accuracy. A synthetic “Hey Station stop listening” played over the tablet's wired output did not stop the listener; speaker volume, acoustics, and actual recognized text were not established by that attempt.

### Private weather override

The repository uses a generic city-center example. To choose your own area, copy `station.local.properties.example` to `station.local.properties` and edit `name`, `latitude`, and `longitude`. The private file, generated `StationConfig.java`, APK, and keystore are excluded from Git. **Do not post your local config or APK in public issues if it reveals your location.** This prototype supports the `America/Denver` timezone only.

Weather data is provided by [Open-Meteo](https://open-meteo.com/), subject to its [terms and attribution/non-commercial-use conditions](https://open-meteo.com/en/terms). Review them before commercial distribution. For camera, microphone, and weather handling, read [Privacy Policy](PRIVACY.md) and [Terms of Service / Use](TERMS_OF_SERVICE.md).
