# TCL Station

An **unofficial, early-stage** Android 12+ dashboard for **arm64-v8a tablets** repurposed as tabletop control panels. **The main branch describes the alpha.6 development build; the latest downloadable release is alpha.5 and does not include these changes.** The current APK contains only arm64-v8a native speech libraries; other CPU architectures are not supported by that APK. The app is written in Java with the Android SDK and does not require Google Play services. It is not affiliated with TCL, Amazon, or Google.

## What works now

- Landscape-first, three-page dashboard with seven tap-to-expand cards; double-tap a card to collapse it.
- Weather from Open-Meteo for a **configurable fixed area** (default: example Denver city-center point; no GPS permission), Denver-time clock, and Android camera/timer/alarm and YouTube Music shortcuts.
- A short, intentionally quiet audio-test beep and a separate **Test spoken reply** button in the expanded Studio Audio card. Its voice switch chooses either the tablet's system TTS engine or the separately installed **sherpa-onnx offline English Piper/Kristin medium model engine**; selecting the model triggers a spoken comparison sample. Unlike the previous alternate within Google TTS, this is a different synthesizer and model. Station does **not** bundle that engine or model in its APK. If the model engine is missing or rejected, Station displays an error and does not silently speak with the system engine. Wired playback still depends on Android audio routing; compare what you actually hear on the Echo Studio.
- Live **on-tablet** camera preview with front/back switching. It is visible only while the preview is open and saves or uploads no footage. The old experimental recorder has been removed; on upgrade, the app attempts to delete clips it created in its own private storage.
- **Speak** remains push-to-talk, including its control inside the camera preview, but now uses the **same bundled local/offline Vosk recognition model** as hands-free rather than opening a separate Android recognizer. Tap to listen for one command (up to nine seconds); tap again to cancel. It requests microphone permission on first use and closes the local microphone when it finishes or Station leaves the foreground. The camera preview closes before Speak starts. No speech audio or transcript is saved or uploaded by Station. Speak and hands-free use separate in-memory recognizers backed by the same on-disk model; the hands-free microphone pauses while Speak has control.
- **Hands-free** is a separate, opt-in continuous listener. Tap **Hands-free: Off** to request microphone permission and start a foreground microphone service; tap **Hands-free: On** or the persistent notification's **Stop listening** action to stop it. While enabled and running, it captures tablet-microphone audio even with the screen off or another app visible. Bundled Vosk recognition runs locally/offline; Station does not save audio or transcripts or send them to a Station server. Say **“Hey Station”** alone for an “I'm listening” spoken acknowledgment, then one or more different commands during a fixed 45-second window; another “Hey Station” restarts the window. Alternatively say **“Hey Station”** or **“Station”** followed immediately by a command (for example, “Hey Station show weather” or “Station stop listening”). This matches *final recognized phrases*, not a guaranteed dedicated wake-word detector: misrecognition and false activations are possible. The listener pauses during Speak and spoken responses, does not start at boot, and may stop if Android kills the service. Continuous listening uses additional battery. It uses the **tablet microphone**, not the Echo Studio microphone through aux.
- Both speech modes match returned text locally to **100 curated phrases for 15 bounded actions** ([full list and limits](VOICE_COMMANDS.md)), plus grammar such as “help,” “set timer for five minutes,” and “set alarm for 7:30 AM.” These are not 100 separate integrations, and parser matching does not guarantee acoustic recognition of every phrase. Actions include configured-area weather, Denver time, front/back live on-tablet camera previews, Android Clock timer/alarm prompts, opening YouTube Music, media play/pause/next keys (Play may resume a paused player; Pause/Next require active playback), Station home, and Stop listening. Alarm/timer setting opens a review UI rather than silently scheduling; media keys may be ignored when no player is active. Time, cached weather, and media keys can run while Station is in the background; other commands require Station in the foreground and otherwise prompt you to open it. Time and weather replies use the selected Android TTS engine: the system provider may process text under its own policy, while the separately installed offline model engine synthesizes locally. Timer duration is limited to two hours; external Clock handles the timer.
- Station can be selected as the Android **Home app** from page 3 using **Make Station Home**. This is a normal, reversible launcher choice, not kiosk mode or a boot receiver. **Home app settings** on the same page opens Android's default-Home settings to restore the previous launcher. Android's status shade, Settings, and app switching remain available.

**Not implemented:** a dedicated wake-word engine, background camera, remote streaming/control, recording, Hermes connection, motion alerts, and EQ. Hands-free is opt-in local phrase recognition, not a guarantee that every “Station” phrase is heard. The Echo Studio aux cable is **tablet audio output only**, not an input from the Studio microphone. The separate **Take photo** shortcut launches another camera app, which may save photos independently. This app has no accounts, analytics, or media upload; see [Privacy Policy](PRIVACY.md).

## Build

Install Android SDK **platform android-36** and **build-tools 36.0.0**, `mise` with `java@21.0.2`, Python 3, and standard JDK tools. Set `ANDROID_HOME` or `ANDROID_SDK_ROOT` to the Android SDK path; otherwise the script checks `$HOME/Work/tools/android-sdk`. Run:

```bash
bash build.sh
```

The build script runs local checks and produces `build/tcl-station-debug.apk`, signed by a locally generated **debug/prototype key**. Do not commit or distribute the private key. The APK is not a production-signed release. To install on your own authorized arm64-v8a tablet, use `adb install -r build/tcl-station-debug.apk`. Camera permission is requested when you open the live preview; microphone permission is requested the first time you tap Speak or enable hands-free. Both modes use the bundled offline Vosk recognizer; the English model adds approximately 41 MB compressed to the APK and needs approximately 71 MB unpacked in the app-specific external-files directory (`Android/data/com.aero.tclstation/files`). After installing, you can opt into Station as Home on page 3; no boot automation is installed. On one Android 12 tablet, automated checks confirmed live local microphone capture, screen-off operation, Speak pause/resume, and explicit Stop. The spoken-reply test produced an Android TTS synthesis request and an audio player routed to the wired headphone output, then listening resumed. A user reported that hands-free Station works in the room, but individual catalog phrases and the new voice's subjective quality have not been systematically checked by a listener; the automated checks cover parser matching and microphone/TTS lifecycle, not room-acoustic accuracy. A synthetic “Hey Station stop listening” played over the tablet's wired output did not stop the listener; speaker volume, acoustics, and actual recognized text were not established by that attempt.

### Optional offline voice model

Station's model choice requires the separately installed upstream sherpa-onnx **v1.13.8 arm64-v8a English Piper Kristin-medium TTS engine** (`com.k2fsa.sherpa.onnx.tts.engine`). **Upgrading from alpha.5 resets its former “alternate voice” choice to the system voice:** the separate engine must be selected explicitly again. Android-wide TTS settings are not changed. The upstream download is [on Hugging Face](https://huggingface.co/csukuangfj2/sherpa-onnx-apk/resolve/main/tts-engine-new/1.13.8/sherpa-onnx-1.13.8-arm64-v8a-eng-tts-engine-vits-piper-en_US-kristin-medium.apk); its local download measured 85,750,855 bytes and SHA-256 `ed36a15921d90295ff374f4ec7c430f7dbda38c4165581bebc135d6dc75d8b93`. Inspect and install that APK only on an authorized tablet. This third-party package is **not** part of Station's source or release APK and occupies additional app storage; it is independent of the SD card. Station leaves the Android-wide default TTS engine unchanged. Open Studio / Audio, tap **Voice: system (tap for offline model)** and then **Test spoken reply**. The app keeps the system voice as an explicit reversible option; if the model package is unavailable or Android silently binds a different engine, Station refuses to synthesize with that other provider. The prototype checks a private Android engine-identity field before sending speech text and will fail closed if an Android update blocks that field, leaving the system voice as the reversible alternative. Android TTS engine providers have their own code and privacy policies; check the upstream source and packaging before installing. The Kristin voice was accepted in one listener's in-room trial; its perceived warmth and depth may differ on other speakers or for other utterances.

This model's [publisher card](https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/kristin/medium/MODEL_CARD) describes a US English female narrator trained on public-domain LibriVox recordings. Station requests a modest 1.08× speech rate only for the model voice. Sherpa's Android TTS service does not currently use Android's pitch field, so Station does **not** claim to lower pitch electronically; the deeper impression must come from choosing the different model, and only a listener can judge it. On a published sample clip, Kristin's measured median voiced fundamental frequency was lower than Amy's; that alone does not establish how every utterance will sound.

### Private weather override

The repository uses a generic city-center example. To choose your own area, copy `station.local.properties.example` to `station.local.properties` and edit `name`, `latitude`, and `longitude`. The private file, generated `StationConfig.java`, APK, and keystore are excluded from Git. **Do not post your local config or APK in public issues if it reveals your location.** This prototype supports the `America/Denver` timezone only.

Weather data is provided by [Open-Meteo](https://open-meteo.com/), subject to its [terms and attribution/non-commercial-use conditions](https://open-meteo.com/en/terms).
